## `/about`

I'm **Nadhif**, but most people call me **Dhiff** or **Rim**.

I'm a software engineer who enjoys working from the backend all the way down to infrastructure — designing APIs, building applications, automating deployments, and occasionally breaking things just to understand how they work.

My main focus:

```text
software engineering
├── backend architecture
├── web application development
├── cloud infrastructure
├── security & penetration testing
└── developer tooling
```

I care more about **how a system works** than how impressive its tech stack looks.
